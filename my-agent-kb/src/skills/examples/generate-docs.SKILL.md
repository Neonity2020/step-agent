## Usage

Use this skill when asked to create or update documentation.

## Steps

1. Read the code to understand what needs documentation
2. Identify the appropriate documentation style:
   - README for project overview
   - API docs for functions/endpoints
   - Comments for inline documentation
3. Write clear, concise documentation
4. Include examples where helpful
5. Update existing docs if needed
