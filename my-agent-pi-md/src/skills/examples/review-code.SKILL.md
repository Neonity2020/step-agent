## Usage

Use this skill when asked to review code for:
- Security vulnerabilities
- Performance issues
- Code quality
- Best practices compliance
- Error handling
- Testing coverage

## Steps

1. Read the relevant code files to understand the codebase
2. Identify potential security issues (SQL injection, XSS, etc.)
3. Check for performance bottlenecks
4. Verify error handling
5. Review naming conventions and code style
6. Check for proper documentation
7. Suggest specific improvements

## Tools

- read
- grep
- bash

## Constraints

- Be constructive and professional
- Prioritize critical issues
- Provide actionable suggestions
- Explain the reasoning behind recommendations
